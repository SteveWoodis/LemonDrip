# Lemonade Mock API — Python/Flask

## Setup (recommended: virtual environment)
```bash
cd python_flask
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

## Endpoints
- `GET /api/health`
- `GET /api/event`
- `GET /api/employees`
- `GET /api/supplies`
- `GET /api/all`
