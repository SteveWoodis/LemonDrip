# Lemonade Mock API (v5)

Built from corrected CSVs and latest EventInfo. Nulls cleaned.

## Setup
```bash
cd node_express_clean_fixed_v5
npm install
npm start
```
Server: http://localhost:3000

## Endpoints
- /api/event
- /api/employees
- /api/supplies
- /api/tips
- /api/tip-tracker
- /api/drink-sales
- /api/additional-fees
- /api/event-runner-fees
- /api/discounts
- /api/regular-lemonade
- /api/fees
- /api/all   (full JSON incl. Totals)
